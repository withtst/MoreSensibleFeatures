# More Sensible Features / 更多符合常理的功能

Project Zomboid B42 模组，提供一组便利功能。当前模组版本为 0.9.10；本次控制台兼容性检查使用游戏 42.22.2（revision `3d39148846`）。

## 功能

- Ctrl+F 关闭并卸下手持光源；右键批量拆卸电子手表、皮带以及撕剪衣物。
- 点燃的营火阻挡所在格；水源处可以批量清洗随身物品。
- K / Ctrl+K 穿戴、脱下防护面罩，或将脱下的面罩放回原容器。
- 从附近容器或地面寻找汽油，为发电机加油。

## 安装

将仓库内容放入 `Zomboid/mods/MoreSensibleFeatures/`，使 `mod.info` 和 `42.21/` 位于该目录下，然后在游戏模组列表中启用。多人游戏需要在相关服务端和客户端安装。

模组声明兼容 B42.21–42.99；具体游戏版本和其他模组的兼容性以实际验证为准。

0.9.10 修正无面罩提示的翻译 key，并将发电机加油动作放入共享加载端，保留网络重建所需的液体容器字段。MP 清洗背包内物品会先转入主背包以满足原版服务端校验，完成或取消后回位；替换型清洗物品在客户端动作开始时记录原有物品 ID。

隔离服务端通过 680 项回归及 4 项加油动作断言，水源候选和 MP 清洗队列通过 Kahlua 模拟检查。营火合成格测试会产生缺少 chunk 的寻路诊断，真实营火生命周期、菜单显示、水/肥皂消耗、物品回位及真实多人同步仍需客户端验证。
